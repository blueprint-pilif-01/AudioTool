# Product

## Register

product

## Platform

web

## Users

AudioTool is for musicians, producers, remixers, educators, and audio creators working with an existing song. Their primary job is to understand what is present in a recording, separate the selected instrument categories, and continue directly into a usable multitrack mix without moving files between unrelated tools.

## Product Purpose

AudioTool turns one uploaded song into an inspectable, editable audio project. Success means a user can upload a file, review detected instruments, correct the selection, generate a dynamic number of clearly labelled stems including residual material, mix them, and return later without losing project or mixer state.

## Positioning

Detect first, then separate every selected instrument category instead of forcing every song into a fixed four-stem template.

## Brand Personality

Precise, capable, focused. The interface should feel like dependable studio equipment: direct enough for a first-time user and dense enough to support repeated editing work.

## Anti-references

Do not reproduce the UI, branding, copy, or assets of vocalremover.org or the other reference services. Do not imply that all songs contain the same four instruments, hide mock processing behind AI claims, or decorate the product like a generic neon AI dashboard.

## Design Principles

- Make the processing state legible at every step.
- Show real audio, real detections, and real project state instead of decorative mockups.
- Keep expert controls available without making the primary workflow ambiguous.
- Treat a dynamic instrument list as the core model, not an edge case.
- Label mock and local processing honestly and keep user audio private by default.

## Accessibility & Inclusion

The web interface must support keyboard navigation, visible focus, accessible status messages, sufficient contrast, reduced motion, and responsive use on desktop and mobile. The complex multitrack editor may recommend a larger screen but must remain operable at narrow widths. Instrument and job states must never be communicated by color alone.
